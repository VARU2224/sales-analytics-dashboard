# Sales Analytics Dashboard

## Project Overview
This project analyzes sales data using Python to understand product performance, profitability, and regional sales trends.

## Objectives
- Analyze total sales and profit.
- Compare sales across products.
- Identify high-performing and low-performing regions.
- Create visualizations to support business decisions.
- Generate actionable business recommendations.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- NumPy
- Google Colab

## Dataset
The sample dataset contains product names, categories, sales regions, sales amounts, profit, and quantities sold.

## Key Performance Indicators
- Total Revenue
- Total Profit
- Quantity Sold
- Sales by Product
- Sales by Region

## Visualizations
The project includes charts for:
- Sales by Product
- Profit by Product
- Sales by Region
- Quantity Sold by Product

## Business Value
The analysis helps identify strong-performing products and regions, while highlighting areas that may need further investigation.

## How to Run
1. Download `Sales_Analytics_Project.ipynb`.
2. Open [Google Colab](https://colab.research.google.com/).
3. Upload the notebook.
4. Upload `sales_data.csv` if using code that reads the CSV file.
5. Run the notebook cells in order.
